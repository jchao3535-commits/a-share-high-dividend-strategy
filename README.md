# A股高分红量化策略研究（近10年）

基于 `AkShare` + `BaoStock` 构建的 A 股高股息量化回测研究框架，覆盖 **2016-05-03 至 2026-11-16**（2015 年报至 2026 半年报，共 22 期半年调仓）。

## 核心设计
- **无未来函数**：年报（`1231`）于次年 5 月第 1 个交易日调仓，中报（`0630`）于当年 9 月第 1 个交易日调仓，且严格校验公告日期 `<= 调仓日`。
- **消除幸存者偏差**：使用 BaoStock `query_all_stock(day=调仓日)` 获取历史真实在市 A 股名单（含后续退市标的）。
- **分层按需下载**：先全量拉取 22 期低频截面表（分红送配 `stock_fhps_em`、业绩报表 `stock_yjbb_em`），再按需下载候选池的日线不复权价（算真实股息率）与后复权价（算含分红总收益）。

## 初步回测结果（纯高股息 Top 30，半年调仓）
- **回测区间**：`2016-05-03` ~ `2026-11-16`
- **策略累计收益**：`124.78%`（年化 `7.98%`，夏普 `0.31`，最大回撤 `-34.50%`）
- **同期基准**：中证红利 `46.40%`（年化 `3.68%`），沪深300 `23.84%`（年化 `2.05%`）

## 目录结构
- `config.py`：回测区间、报告期与交易成本配置
- `download_cross_sections.py`：下载交易日历、历史股票名单、22 期分红与财报截面表
- `download_prices.py`：按需下载候选池日线数据（不复权 + 后复权 + PE/PB）
- `backtest.py`：纯高股息回测与净值可视化
- `results/`：回测净值、持仓明细、绩效汇总与净值曲线图
