# A股高分红量化策略研究（近10年）

基于 `AkShare` + `BaoStock` 构建的 A 股高股息多因子量化回测研究框架，覆盖 **2016-05-03 至 2026-11-16**（近 10 年完整周期）。

## 核心设计（无未来函数 & 消除幸存者偏差）
- **无未来函数**：年报（`1231`）于次年 5 月第 1 个交易日调仓，中报（`0630`）于当年 9 月第 1 个交易日调仓，三季报（`0930`）于当年 11 月第 1 个交易日调仓，且严格校验分红公告日期 `<= 调仓日`。
- **消除幸存者偏差**：使用 BaoStock `query_all_stock(day=调仓日)` 获取历史真实在市 A 股名单（含后续退市标的）。
- **分层按需下载**：先全量拉取各报告期低频截面表（分红送配 `stock_fhps_em`、业绩报表 `stock_yjbb_em`），再按需下载候选池的日线不复权价（算真实股息率）与后复权价（算含分红总收益）。

## 调仓频率说明（易混事项提示）
A 股一年只有 **3 个法定财报披露截止日**（年报与一季报均在 `4月30日` 前，半年报在 `8月31日` 前，三季报在 `10月31日` 前）：
- **半年调仓（`5/9月`）**：对应年报与半年报，一年 2 次，抓住了 A 股最核心的两次分红财报，综合表现最优且省心。
- **财报季调仓（`5/9/11月`）**：严格按三大财报季落地调仓，一年 3 次。
- **季频调仓（`2/5/9/11月`）**：**注意：2 月初尚未发布年报**，因此 2 月调仓沿用上一年 **三季报（`0930`）** 基本面数据，仅结合 2 月初最新股价/PE/总市值做估值再平衡，绝不使用未披露年报。

## 目录结构
- `config.py`：回测区间、报告期与交易成本配置
- `download_cross_sections.py` / `download_quarterly.py`：下载交易日历、历史股票名单、年报/中报/季报分红与财报截面表
- `download_prices.py`：按需下载候选池日线数据（不复权 + 后复权 + PE/PB）
- `backtest.py`：纯高股息基线回测
- `backtest_mktcap_groups.py` / `backtest_pe_groups.py` / `backtest_roe_groups.py`：市值、PE、ROE 单因子分组回测
- `backtest_scoring.py` / `backtest_scoring_guarded.py` / `backtest_industry_cap.py` / `backtest_quarterly.py`：多因子打分、底线过滤、行业限制与季频调仓回测
- `compare_tech_indices.py`：与科创50、创业板指的多窗口对比
- `results/`：回测净值、持仓明细、绩效汇总与净值曲线图
